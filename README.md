# 貸金クエスト 🪙

○×バトルで学ぶ、**貸金業務取扱主任者試験**の学習RPGです。ドラクエ風に敵（問題）を倒しながら、試験4科目＋本試験ボスを攻略します。

## 遊び方
1. 名前を入力して「ぼうけんを はじめる」
2. マップから科目エリアを選ぶ
3. ○×問題に正解すると敵に攻撃、不正解だと反撃を受ける
4. 敵を倒すとレベルアップ（HP・攻撃力アップ）、次のエリアが解放

## エリア（試験科目）
- かしきんぎょうほうの まち … 法及び関係法令
- みんぽうの もり … 貸付け・取引に関する法令
- ほごほうの みさき … 資金需要者等の保護
- ざいむの とう … 財務及び会計
- ほんしけん かいじょう … 全分野ミックス（ラスボス）

## 公開
`index.html` 1ファイルで完結しています。GitHub Pages で公開しています。

## 注意
学習用ゲームです。出題は学習目的の要点整理であり、実際の試験問題・法令の正式な条文とは異なる場合があります。
